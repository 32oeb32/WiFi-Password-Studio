# Security policy

## Reporting vulnerabilities

Please report suspected security issues privately to **dev32@apex32-secure.com** rather than including real secrets, vulnerable hosts, or personally identifying examples in public GitHub issues.

Include the Python version, operating system, affected program option, reproduction steps using **synthetic inputs only**, and expected versus actual behavior.

No public support SLA or security response timeframe is currently promised.

## Supported status

The source is a community preview. Releases and a formal supported-version matrix will be established after public qualification. This is not a claim of audited cryptographic security.
